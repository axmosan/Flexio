Flexio is a script launcher panel that works across Adobe After Effects, Premiere Pro, Photoshop, and Illustrator.

# Background
Currently, while there are script launchers like Kbar3 available for After Effects, there are no properly functional script launchers for other Adobe products. As a result, even if you create your own scripts, it takes a lot of effort to actually run them. This is a real waste.
To solve this problem, I’ve created a launcher script that works natively with four different software applications. It’s designed to be more compatible with FLEX and to function effectively.
